## Projetos em destaque

**🛢️ Relatórios Executivos com GenAI — Óleo & Gás**
Sistema de geração automática de relatórios executivos para plataformas de petróleo e gás. Reduziu 40% os custos com APIs de IA via few-shot learning, n-gram e otimização de prompts.
`LangChain` `Celery` `Redis` `Django` `MongoDB` `Docker` `DeepEval` `LLM-as-Judge`
→ Apresentado no **Rio Oil & Gas 2026**

**🏥 Sumários Clínicos — Fiocruz**
Gerador de sumários clínicos para transição de cuidados de pacientes, com chatbot para informações críticas e avaliação com LLM-as-Judge + feedback humano.
`RAG` `Embeddings` `LangChain` `DeepEval`
→ Apresentado no **57º Simpósio de Pesquisa Operacional**

**🔬 Pipeline de Extração Clínica**
Automação de extração de entidades para expansão de base médica de múltiplos hospitais brasileiros de grande porte.
`NLP` `regex` `Generative AI` `Python`

**💬 Chatbot Text-to-SQL & Agentes**
Chatbot com consulta a SQL em linguagem natural, orquestração de agentes, fine-tuning de modelos e avaliação comparativa de embeddings.
`LangGraph` `Text-to-SQL` `Fine-tuning` `Pinecone` `Qdrant`
